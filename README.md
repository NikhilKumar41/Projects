# Software-Based 3D DNA Helix Renderer [Inspired by yt- @Tsoding]

This project is a lightweight 3D wireframe renderer built from scratch using JavaScript and HTML5 Canvas.

It demonstrates manual 3D coordinate transformations, perspective projection, and indexed wireframe rendering without using WebGL, OpenGL, or external 3D libraries.

The rendered model is a rotating DNA double-helix constructed entirely from 3D coordinates.

## Features
- Software-based 3D rendering pipeline
- Manual perspective projection (x/z, y/z)
- Coordinate-based wireframe geometry
- Real-time rotation and animation
- No external 3D libraries

## How to Run
1. Clone or download the repository
2. Open `page.html` in a web browser

## Purpose
This project was created to understand and implement the fundamentals of 3D graphics rendering at a low level.
